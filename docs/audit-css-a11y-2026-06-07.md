# CSS + Accessibility Audit — 2026-06-07

Read-only audit of `static/main.css` and the `templates/` tree against WCAG 2.2
AA and general maintainability practice. Almost everything it found has since
been fixed or removed; only the open findings are kept below.

**Resolved or obsolete:** banner landmark nested inside `<main>` (the header now
renders from `block site_chrome`, outside `<main>`); missing skip-link
(`templates/base.html:26`, styled at `static/main.css:215`); coarse
`<tbody aria-live="polite">` on the board; dead `.weekly-grid-table`,
`.no-pools`, and `.no-beaches` rules; every `.fn-*` field-notes finding, along
with the missing `js/field-notes.js` and `js/scrollspy.js` script tags, now that
`templates/field-notes/` is deleted; `.fallback`, which now has a rule in
`main.css`; and all the keyboard, focus, contrast, and motion findings.

## Open

- **Issue**: `.club-list`, `.pricing-note`, `.weekly-grid-head`, and
  `.weekly-grid-session` exist in markup but have no rules in `static/main.css`.
  **Location**: `templates/spots/page.html:44, 96, 407, 439, 458, 480`
  **Why it matters**: they are semantic hooks with no styling and no JS reader,
  so they are either unused or waiting on a design decision.
  **Suggested fix**: style them deliberately or delete them from the template.
  `.detail-root` is deliberately unstyled: `static/js/detail.js:203` queries it,
  so it is a load-bearing JS hook, not a dead class.
